# ファイルの読み方 {#how-the-files-are-read}

読むのは `Mods/terrains/<theatre>/surface/*.surface5`（地面のメッシュ）、`Scenes/*.scn5`（オブジェクトの立つ場所と、各モデルの箱）、`AirfieldsTaxiways/*.rn4`、そして `map/towns.lua`（地名。テキストとして読み、実行はしません）だけです。暗号化された `terrain.cfg.lua.pak.crypt`、`manifest.bin`、プログラム自体は読みません。

`.surface5` の形式は公開されていません。ファイルから読み取った構造は、[`heat3d_ext_dcs/surface5.py`](https://github.com/Holdi601/3DHeat-Ext-DCS/blob/main/heat3d_ext_dcs/surface5.py) に書かれています。要点は次の通りです: タイルの記録の索引（変換、範囲、型付きのバイト列の一覧。各一覧の後に、それを描くシェーダーと材質が続く）、その後に生のデータ。圧縮も暗号化もされていません。タイルの `Pbase` の列が頂点を持ちます。`Land` として描かれるグループが三角形と、三角形ごとの `TRITYPE` を持ち、その最下位ビットが海を示します。そのほかのグループが、上記の種類を与える重ね塗りです。

## 確かめたこと {#verified}

- **`list`** は、インストールされたすべてのシアターの索引を読みました（それぞれ数百万から数千万の地面の頂点）。サンプルしたすべてのタイルは、もっともらしいメートルに復号されました。
- 二つのシアターの領域で、`towns.lua` の町は、地面の頂点から数メートル以内、陸上に、N of N で着地しました。最も高い地面は、実際の山頂と10m以内で一致しました。飛行場、川、村、道路は、それぞれの種類で表示されました。両方のレベルはビューアで読み込め、同じDCSのメートルの町の目印が地面の上にありました。
- シーンの領域では、建物の配置がその地面に着地しました。滑走路のライトはゲームの滑走路をなぞり、貨車と壁の区画は、復号した向きに、すべてそろって並びました。
- `tests/` は、同じ構造の `.surface5` ファイルを作るので、ゲームのデータはここに保存されません。`tests/test_real_install.py` は、テストを実行しているマシンのインストールで動き、なければ飛ばされます。

**未確認:** 大きなシアターの全体を一つのレベルにすること（上記のサイズの保護はそのためにあります）、そしてテストしたもの以外のDCSのバージョン。

## 読まれないもの {#not-read}

- **形としての建物**（モデルは `Models/` の `.edm`）: 意図して箱だけです。その構造、そしてシーンの構造は [`heat3d_ext_dcs/scene5.py`](https://github.com/Holdi601/3DHeat-Ext-DCS/blob/main/heat3d_ext_dcs/scene5.py) に書かれています。インストールされたすべてのシアターが読めます（別の構造を持つ古い二つのシアターも、このリーダーは知っています）。
- 木、ライト、シーンのそのほかのオブジェクト: 読みますが、描きません。
- **グラフとしての道路網**（`roads/*.rn4`）: デコードしていません。
- テクスチャ、木、海の波、地形の低い詳細度のレベル。
