# Построение уровня: `level` {#building-a-level-level}

```text
heat3d-dcs-maps level <theatre> -o <folder> [--dcs FOLDER] [--name NAME]
                      [--around LAT LON KM | --bounds X0 Z0 X1 Z1] [--cell M]
                      [--seabed] [--no-water] [--no-buildings] [--force]
                      [--projection LON0 FE FN]
```

## Пошагово {#step-by-step}

Впервые в командной строке? Сначала прочитайте [С чего начать](before-you-start.md).

1. Найдите имя папки театра с помощью [`list`](list.md).
2. Для небольшого театра постройте его целиком: `heat3d-dcs-maps level <theatre> -o levels`.
3. Для большого выберите регион: `--around <lat> <lon> <km>` (квадрат такого размера в обе
   стороны от точки) или `--bounds X0 Z0 X1 Z1` в метрах DCS. Назовите его через `--name`.
4. Команда выводит тайлы по мере чтения, число треугольников, записанный файл и сколько городов
   театра попадает на землю — проверка проекции, которая должна показать «N из N».
5. Загрузите `<folder>/<name>.glb` в панель «Фон / уровень» просмотрщика и включите
   **Снятый цвет**, чтобы увидеть классы поверхности.

## Параметры {#options}

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `theatre` | - | имя папки в `Mods\terrains`, как его выводит `list` (любой регистр) |
| `-o`, `--out` | обязателен | папка, куда писать `<name>.glb` и `<name>.json` |
| `--dcs FOLDER` | находится сам | папка DCS World ([где её ищут](list.md#where-the-install-is-found)) |
| `--name NAME` | название театра | имя уровня и его файлов |
| `--around LAT LON KM` | - | только квадрат такого размера в километрах в обе стороны от точки |
| `--bounds X0 Z0 X1 Z1` | - | только этот прямоугольник, в метрах DCS (x — север, z — восток) |
| `--cell M` | `0` | разрежить сетку: каждая вершина в пределах *M* метров становится одной (0: собственные треугольники игры) |
| `--seabed` | выключен | сохранить морское дно как землю (по умолчанию его не берут) |
| `--no-water` | выключен | не брать плоское море |
| `--no-buildings` | выключен | не брать здания сцены театра |
| `--force` | выключен | экспортировать очень большую карту целиком в полной детализации |
| `--projection LON0 FE FN` | как у театра | константы проекции Transverse Mercator для театра, который этот инструмент не знает ([fit](fit.md)) |

Все параметры, как их выводит программа: [Справка по командам](../cli-reference.md).

## Размер {#size}

Сетка игры адаптивная: открытое море — в треугольниках в километры, побережья и дороги — в
несколько метров. Небольшой театр — это несколько миллионов треугольников; большие — десятки
миллионов вершин. Если для чтения больше 30 миллионов вершин, `level` останавливается (код
выхода 1) и просит регион, более редкую сетку (`--cell 50`) или `--force`.

Код выхода: 0 — готово; 1 — ошибка или слишком большой; 2 — установка или театр не найдены
(выводится список найденных театров).

## Примеры {#examples}

```bash
heat3d-dcs-maps level <theatre> -o levels                                       # целиком, полная детализация
heat3d-dcs-maps level <theatre> --around <lat> <lon> 12 -o levels --name Part   # квадрат 24 км
heat3d-dcs-maps level <theatre> --bounds 1000 2000 1390 2390 -o levels          # прямоугольник в метрах DCS
heat3d-dcs-maps level <theatre> --cell 50 -o levels                             # целиком, разрежено до 50 м
heat3d-dcs-maps level <theatre> --no-buildings --no-water -o levels             # только земля
```

Что находится в файлах: [Файлы уровня](output.md).
