# Εύρεση θεάτρων: `list` {#finding-theatres-list}

```text
heat3d-dcs-maps list [--dcs FOLDER]
```

Δεν έχετε ξαναδουλέψει με τη γραμμή εντολών; Διαβάστε πρώτα το [Πριν ξεκινήσετε](before-you-start.md).

1. Εγκαταστήστε μία φορά: `git clone https://github.com/Holdi601/3DHeat-Ext-DCS`, ανοίξτε
   τερματικό μέσα σε αυτόν τον φάκελο και τρέξτε `python -m pip install -e .` (Python 3.10
   ή νεότερη· φέρνει το numpy, και το pyarrow για το `fit` σε `.parquet`).
2. Τρέξτε `heat3d-dcs-maps list`.
3. Κάθε εγκατεστημένο θέατρο τυπώνει μία γραμμή: το όνομα του φακέλου του (το όνομα που παίρνουν οι άλλες εντολές),
   το μέγεθος του αρχείου εδάφους του, τα πλακίδιά του και τις κορυφές του, αν είναι γνωστή η προβολή
   γεωγραφικού πλάτους/μήκους του, και αν διαβάζεται. Στο τέλος κάθε γραμμής πρέπει να δείτε `readable`.

![list σε μια συνθετική εγκατάσταση](../assets/img/list.svg)

Η εικόνα είναι εκτέλεση σε εγκατάσταση που φτιάχνουν τα τεστ (`tests/synth.py`), όχι στο παιχνίδι.

## Πού βρίσκεται η εγκατάσταση {#where-the-install-is-found}

`--dcs <folder>` (ο φάκελος που περιέχει το `Mods\terrains`) ή η μεταβλητή περιβάλλοντος `DCS_PATH`· αλλιώς ψάχνονται το μητρώο, οι βιβλιοθήκες του Steam και οι συνήθεις φάκελοι.

| Επιλογή | Τι κάνει |
|---|---|
| `--dcs FOLDER` | ο φάκελος του DCS World, αυτός που περιέχει το `Mods\terrains` |

Κωδικός εξόδου: 0 ολοκληρώθηκε, 2 δεν βρέθηκε εγκατάσταση ή θέατρο.
