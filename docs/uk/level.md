# Побудова рівня: `level` {#building-a-level-level}

```text
heat3d-dcs-maps level <theatre> -o <folder> [--dcs FOLDER] [--name NAME]
                      [--around LAT LON KM | --bounds X0 Z0 X1 Z1] [--cell M]
                      [--seabed] [--no-water] [--no-buildings] [--force]
                      [--projection LON0 FE FN]
```

## Крок за кроком {#step-by-step}

Ви лише починаєте працювати з командним рядком? Спершу прочитайте [Перш ніж почати](before-you-start.md).

1. Знайдіть назву папки театру за допомогою [`list`](list.md).
2. Для невеликого театру побудуйте його цілком: `heat3d-dcs-maps level <theatre> -o levels`.
3. Для великого оберіть регіон: `--around <lat> <lon> <km>` (квадрат стільки км
   в обидва боки від точки) або `--bounds X0 Z0 X1 Z1` у метрах DCS. Назвіть його
   параметром `--name`.
4. Команда виводить тайли, коли їх читає, кількість трикутників, записаний файл і
   скільки міст театру лежить на землі — перевірка проєкції, яка має показати
   «N з N».
5. Завантажте `<folder>/<name>.glb` у панелі «Тло / рівень» переглядача і увімкніть
   **Знятий колір**, щоб побачити класи землі.

## Параметри {#options}

| Параметр | За замовчуванням | Що робить |
|---|---|---|
| `theatre` | - | назва папки в `Mods\terrains`, як її виводить `list` (будь-який регістр) |
| `-o`, `--out` | обов'язковий | папка, куди записати `<name>.glb` і `<name>.json` |
| `--dcs FOLDER` | знаходиться | папка DCS World ([де її шукають](list.md#where-the-install-is-found)) |
| `--name NAME` | назва театру | назва рівня та його файлів |
| `--around LAT LON KM` | - | лише квадрат стільки км в обидва боки від точки |
| `--bounds X0 Z0 X1 Z1` | - | лише цей прямокутник, у метрах DCS (x — північ, z — схід) |
| `--cell M` | `0` | розрідити сітку: кожна вершина в межах *M* метрів стає однією (0: власні трикутники гри) |
| `--seabed` | вимкнено | залишити морське дно як землю (за замовчуванням його пропускають) |
| `--no-water` | вимкнено | не включати рівну поверхню моря |
| `--no-buildings` | вимкнено | не включати будівлі сцени театру |
| `--force` | вимкнено | експортувати дуже велику карту цілком з повною деталізацією |
| `--projection LON0 FE FN` | театру | константи Transverse Mercator для театру, якого цей інструмент не знає ([fit](fit.md)) |

Кожен параметр так, як його виводить програма: [Довідка з команд](../cli-reference.md).

## Розмір {#size}

Сітка гри адаптивна: відкрите море — трикутники завширшки в кілометри, узбережжя й
дороги — в кілька метрів. Невеликий театр — це кілька мільйонів трикутників; великі
мають десятки мільйонів вершин. Понад 30 мільйонів вершин для читання `level`
зупиняється (код виходу 1) і просить регіон, рідшу сітку (`--cell 50`) або `--force`.

Код виходу: 0 — готово; 1 — помилка або занадто велике; 2 — інсталяцію або театр не
знайдено (виводиться список знайдених театрів).

## Приклади {#examples}

```bash
heat3d-dcs-maps level <theatre> -o levels                                       # цілком, повна деталізація
heat3d-dcs-maps level <theatre> --around <lat> <lon> 12 -o levels --name Part   # квадрат 24 км
heat3d-dcs-maps level <theatre> --bounds 1000 2000 1390 2390 -o levels          # прямокутник у метрах DCS
heat3d-dcs-maps level <theatre> --cell 50 -o levels                             # цілком, прорідженою до 50 м
heat3d-dcs-maps level <theatre> --no-buildings --no-water -o levels             # лише земля
```

Що є у файлах: [Файли рівня](output.md).
