# Прављење нивоа: `level` {#building-a-level-level}

```text
heat3d-dcs-maps level <theatre> -o <folder> [--dcs FOLDER] [--name NAME]
                      [--around LAT LON KM | --bounds X0 Z0 X1 Z1] [--cell M]
                      [--seabed] [--no-water] [--no-buildings] [--force]
                      [--projection LON0 FE FN]
```

## Корак по корак {#step-by-step}

Први пут у командној линији? Прво прочитајте [Пре почетка](before-you-start.md).

1. Нађите име фасцикле театра помоћу [`list`](list.md).
2. За мали театар направите га цело: `heat3d-dcs-maps level <theatre> -o levels`.
3. За велики изаберите регион: `--around <lat> <lon> <km>` (квадрат толико km с обе
   стране тачке) или `--bounds X0 Z0 X1 Z1` у DCS метрима. Дајте му име помоћу `--name`.
4. Команда исписује плочице док их чита, број троуглова, написану датотеку, и
   колико градова театра пада на тло - провера пројекције која би требало да
   пише „N од N".
5. Учитајте `<folder>/<name>.glb` на панел Позадина / ниво приказивача и укључи
   **Снимљена боја** да видите класе тла.

## Опције {#options}

| Опција | Подразумевано | Шта ради |
|---|---|---|
| `theatre` | - | име фасцикле под `Mods\terrains`, онако како га исписује `list` (велика или мала слова) |
| `-o`, `--out` | обавезно | фасцикла у коју се пишу `<name>.glb` и `<name>.json` |
| `--dcs FOLDER` | пронађено | фасцикла DCS World-а ([где се налази](list.md#where-the-install-is-found)) |
| `--name NAME` | назив театра | име нивоа, и његових датотека |
| `--around LAT LON KM` | - | само квадрат толико km с обе стране тачке |
| `--bounds X0 Z0 X1 Z1` | - | само ова кутија, у DCS метрима (x на север, z на исток) |
| `--cell M` | `0` | проређује мрежу: свако теме у кругу од *M* метара постаје једно (0: сопствени троуглови игре) |
| `--seabed` | искључено | задржите морско дно као тло (подразумевано се изоставља) |
| `--no-water` | искључено | изоставите равно море |
| `--no-buildings` | искључено | изоставите зграде из сцене театра |
| `--force` | искључено | извези врло велику мапу целу у пуном детаљу |
| `--projection LON0 FE FN` | театра | Transverse Mercator константе за театар који овај алат не зна ([fit](fit.md)) |

Свака опција, онако како је програм исписује: [Референца команди](../cli-reference.md).

## Величина {#size}

Мрежа игре је адаптивна - отворено море у троуглима од километара, обале
и путеви у неколико метара. Мали театар је неколико милиона троуглова; велики
су десетине милиона темена. Преко 30 милиона темена за читање, `level` се
зауставља (излазни статус 1) и тражи регион, ређу мрежу (`--cell 50`) или
`--force`.

Излазни статус: 0 готово; 1 неуспело или превелико; 2 инсталација или театар
нису нађени (исписују се нађени театри).

## Примери {#examples}

```bash
heat3d-dcs-maps level <theatre> -o levels                                       # цело, пун детаљ
heat3d-dcs-maps level <theatre> --around <lat> <lon> 12 -o levels --name Part   # квадрат од 24 km
heat3d-dcs-maps level <theatre> --bounds 1000 2000 1390 2390 -o levels          # кутија у DCS метрима
heat3d-dcs-maps level <theatre> --cell 50 -o levels                             # цело, проређено на 50 m
heat3d-dcs-maps level <theatre> --no-buildings --no-water -o levels             # само тло
```

Шта је у датотекама: [Датотеке нивоа](output.md).
